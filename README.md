# Card Betting Model

Predicts over/under card outcomes in football matches and identifies value bets across multiple bookmakers.

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run the full daily pipeline
python daily_analysis.py

# Skip scraping, use cached data
python daily_analysis.py --skip-scrape

# Retrain the ML model on historical data
python daily_analysis.py --retrain
```

Or double-click `run_daily.bat` on Windows.

## Pipeline Steps

1. **Scrape team stats** - Downloads card statistics for 19 leagues from betaminic.com
2. **Scrape referee stats** - Collects referee card tendencies from oddalerts.com
3. **Collect odds** - Gathers card over/under odds from The Odds API (multi-bookmaker), Betfair, and onemillionpredictions
4. **Predict** - Builds features, runs ML model + Poisson ensemble to get P(Over X.5 cards)
5. **Merge odds** - Combines predictions with bookmaker odds
6. **Detect value** - Flags bets where model edge > 3%, calculates EV% and Kelly stake

## Model

- **Gradient Boosting Classifier** trained on 25,000+ historical matches across 15 leagues
- **Poisson regression** baseline for count-data modeling
- **Ensemble**: 60% ML + 40% Poisson
- **Walk-forward cross-validation** for honest evaluation (no data leakage)
- Features: rolling team card averages, referee tendencies, interaction terms, league context

## Bookmakers

Odds are collected from: The Odds API (Unibet, William Hill, Betfair, Paddy Power, Pinnacle, etc.), Betfair Exchange, and onemillionpredictions.com consensus.

## The Odds API Setup (Recommended)

Get a **free** API key (500 credits/month) at https://the-odds-api.com/#get-access

Set the environment variable:
```
THEODDS_API_KEY=your_api_key_here
```

This gives you card over/under odds from multiple bookmakers across 5 leagues. Daily usage is ~10 credits, so the free tier lasts the whole month.

## Betfair Setup (Optional)

To enable Betfair Exchange odds, set these environment variables:
```
BETFAIR_USERNAME=your_username
BETFAIR_PASSWORD=your_password
BETFAIR_APP_KEY=your_app_key
BETFAIR_CERTS_DIR=./certs
```
